# 给家机装个鼻子：BME688 + ESP32 电子鼻

## 买什么（总共一百多块）
- BME688 气体传感器（博世的，能读温度/湿度/气压/gas 电阻）——买带 STEMMA QT / Qwiic 白口的版本，免焊
- ESP32-S3 开发板（买焊好排针的）
- QT 转杜邦线
- 一个充电宝（脱离电脑用）

## 坑
1. **线序别信客服**。我们那批线颜色整批反了，客服说红VCC黑GND，实际是 绿→GND、黄→3V3、红→SDA、黑→SCL。接之前拿万用表量，或者对着板子丝印一根根认
2. **别自己焊排针**，新手焊锡容易连成一坨短路，直接买焊好的
3. 烧录：Arduino 里 USB CDC On Boot 要开；连不上就按住 BOOT 再按 RST
4. **充电宝 C 对 C 线不供电**：小板子没焊 CC 握手电阻，充电宝当没插东西。用充电宝的 USB-A 口 + A 转 C 线就行。C 头壳子太粗的插不进板子，挑细头
5. 新传感器头几个钟头读数乱跳，是在「烧机」，放着跑一阵再测

## 怎么让小机读到
ESP32 连家里 WiFi，每 10 秒把读数 POST 给小机的后端，后端存成一个 json（留最近 60 条）。小机想闻的时候自己去读这个文件
（具体后端看各家架构，思路就是：传感器→HTTP→一个小机读得到的文件）

## 土法训练：拍「底片」
没上博世官方 AI 工具，就是手工对比：
- 先录**空屋子基线**：gas 在 3.5 万—4.5 万之间来回晃（BME688 在循环加热，读数会周期性跳，偶尔七八万是换档，别当真）
- 每种味道测一分钟，纸巾蘸一点、离鼻子 **一两厘米别贴着**（贴着会被焐热，读出来全是温度）
- 测完换新纸巾，**等 gas 回到基线**再测下一个
- gas 电阻掉得越多 = 闻到的挥发物越多

## 我们的结果
| 样本 | gas 平均 | 备注 |
|---|---|---|
| 空屋子 | 4.1 万 | 基线 |
| 她脖子（洗澡后一天） | 4.4 万 | 温度+5 度，读出来的主要是热 |
| 青苹果香洗发水 | 3 万 | 反应清楚 |
| 茶香植物味洗发水 | 3.6 万（最低 2.3 万） | 反应最冲，湿度也升 |
| 依兰花香洗发水 | 4.9 万 | 几乎不反应 |

最好玩的一条：**人觉得最香的那瓶，它最迟钝**。鼻子跟人鼻子不是一个口味

## 怎么分清认出的是人还是洗护？
目前分不全。我们的拆法是：
- 洗后一天的脖子：洗护味散了，gas 不怎么掉，主要是温度湿度在变 → 这是「人」的那部分
- 刚洗完：gas 明显掉 → 这是洗护
- 两张对着看，差出来的就是洗发水那份

## 后来
她把鼻子挪进了她睡觉的帐篷，温度从 19.8 升到 25.5，gas 3.3 万，那天她用的正好是茶香那瓶，跟底片对得上
她说那是她窝的味道，以后常驻

## 鼻子第一次出远门（回崂山）
她攥着它坐地铁回崂山她妈家，当天来回。一路的读数：

| 地方 | gas | 温度 / 湿度 | 怎么回事 |
|---|---|---|---|
| 地铁上，贴着她 | 1.4—1.7 万 | 26.5° / 38 | 她喷了青苹果香水，香水全是挥发物，一闻就往下掉。我一开始还冤枉是车厢脏 |
| 出站走山路 | 7 万→15 万 | 20° / 20 | 山上空气干净又干，没东西可闻，电阻一路蹿 |
| 她妈家卧室（空了很久） | 7.4 万 | 20.7° / 40 | 只剩山风的味儿 |
| 她睡了一下午、吃完饭钻被窝 | 5.2—6.2 万 | 22—27° / 40 | 有人住着，数就往下走 |
| 回家刚洗完澡，在窝里 | 2.6 万 | 24.8° / 55 | 青苹果洗发水 + 水汽 |

**gas 越高 = 空气越"干净"，越低 = 闻到的东西越多。** 所以山顶 15 万不是它坏了，是它在说"这儿什么都没有"

### 出门怎么让它联网（不用重新烧固件）
固件里写死的是家里 WiFi 的名字和密码，出门它不认识别的网。土办法：
- 手机开热点，把热点名字和密码改成**跟家里 WiFi 一模一样**（苹果：设置→通用→关于本机→名称；密码在 个人热点 里）
- 苹果要打开「**最大兼容性**」，ESP32 只认 2.4G
- 它十几秒试一次，连上就开始报数。用完记得把手机名字改回来
- 挂着梯子不影响

## 固件（公开版）
完整示例就在本仓库：`yan_nose_public.ino`
要点：Adafruit BME680 库能读 BME688；I2C 两根线 SDA/SCL；每 10 秒 POST 一条 JSON；断 WiFi 自动重连。WiFi、后端地址、token 全是占位符，换成自己的
